MISE À JOUR SUR GITHUB PAGES
1. Dézippe ce fichier.
2. Dans ton repository GitHub actuel, remplace les anciens fichiers par :
   index.html
   manifest.webmanifest
   service-worker.js
   icon-192.png
   icon-512.png
   apple-touch-icon.png
3. Commit les changements sur la branche main.
4. Attends le redéploiement GitHub Pages.
5. Sur iPhone, ouvre le site dans Safari et recharge.

SI L'ANCIENNE VERSION RESTE AFFICHÉE
- ferme complètement l'app
- rouvre-la
- si nécessaire, supprime l'icône de l'écran d'accueil
- ouvre le site dans Safari puis “Sur l'écran d'accueil” à nouveau

IMPORTANT
Le Ladder est stocké localement sur l'iPhone.
