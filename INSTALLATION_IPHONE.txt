DARTS NIGHT — PWA iPHONE

Ce dossier contient une version installable de l'app sur iPhone.

Fichiers :
- index.html : application
- manifest.webmanifest : infos PWA
- service-worker.js : mode hors ligne
- icon-192.png / icon-512.png : icônes PWA
- apple-touch-icon.png : icône iPhone

IMPORTANT
Une PWA doit être ouverte depuis une adresse HTTPS pour que l'installation et le mode hors ligne fonctionnent correctement.
Le plus simple est de publier ce dossier gratuitement sur GitHub Pages.

INSTALLATION AVEC GITHUB PAGES

1. Va sur github.com et connecte-toi.
2. Crée un nouveau repository, par exemple : darts-night
3. Ajoute tous les fichiers de ce dossier à la racine du repository.
4. Dans le repository :
   Settings > Pages
5. Dans "Build and deployment" :
   Source : Deploy from a branch
   Branch : main
   Folder : /(root)
6. Clique Save.
7. Après quelques instants, GitHub affichera l'adresse HTTPS de ton site.

SUR IPHONE

1. Ouvre cette adresse dans Safari.
2. Appuie sur le bouton Partager.
3. Choisis "Sur l'écran d'accueil".
4. Appuie sur "Ajouter".
5. Lance ensuite Darts Night depuis son icône.

Le scoreboard s'ouvrira comme une application indépendante.
Après un premier chargement, les fichiers de l'app sont mis en cache pour fonctionner hors ligne.

SAUVEGARDE
Les parties restent stockées localement sur l'iPhone via le navigateur / la PWA.
Elles ne sont pas encore synchronisées avec ton ordinateur.
